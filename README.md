# SaikoMC

Economy, stat scoreboard, shop, auction house, spawners and gambling for Spigot / Paper 1.20+ (Java 17+).
Optional: LuckPerms (rank) and PlaceholderAPI (clan).

Build: `mvn clean package` -> `target/SaikoMC.jar` (or use the GitHub Actions workflow).
Config: `plugins/SaikoMC/config.yml` (+ `shop.yml` for prices), apply with `/saikomc reload`.

Netherite ingot, netherite scrap and ancient debris are sell-only in shop.yml (buy: 0).
